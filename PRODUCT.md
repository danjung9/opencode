# Warcode

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Warcode is a personal desktop coding agent for the owner of this fork.

## Product Purpose

Build on the existing application's coding, project, and model-provider workflows under the Warcode identity.

## Operating Context

The primary interface runs in an Electron desktop window. The shared interface uses Solid and the existing workspace packages. Coding sessions connect to a local service.

## Capabilities and Constraints

Preserve the existing coding workflows and model-provider integrations. Apply the rebrand across the application, including names, visual assets, native app identity, and application copy.

## Brand Commitments

The product name is Warcode. The owner approved the Workroom mockup, with warm light surfaces and orange actions. The existing desktop app supplies the skeleton and foundation, including navigation, sessions, and coding workflows.
