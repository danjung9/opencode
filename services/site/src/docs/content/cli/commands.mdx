---
title: "Commands"
description: "Reference for the warcode command line."
---

Every command accepts `--help` for its full flag list, for example `warcode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ warcode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Warcode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @warcode/cli
      - run: warcode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ warcode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ warcode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ warcode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ warcode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ warcode run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ warcode run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ warcode run --auto "Fix the failing test"
```

Create the session archived so scripted or CI runs stay out of session lists and the inbox. The session still exists: `warcode session list` includes it, and you can open it by ID.

```bash
$ warcode run --archived "Review this diff"
```

View all subcommands and flags.

```bash
$ warcode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ warcode mini
```

Continue the last session.

```bash
$ warcode mini --continue
```

Start with a model and an initial prompt.

```bash
$ warcode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ warcode mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ warcode mini --help
```

## session

Manages sessions.

```bash
$ warcode session list
```

Limit the list and print JSON.

```bash
$ warcode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ warcode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ warcode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ warcode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ warcode session import session.json
```

Import into a specific directory.

```bash
$ warcode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ warcode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ warcode auth list
```

List them as JSON.

```bash
$ warcode auth list --format json
```

Log in to a provider.

```bash
$ warcode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ warcode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ warcode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ warcode auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ warcode auth export anthropic > credentials.json
$ warcode auth import credentials.json
```

View all subcommands and flags.

```bash
$ warcode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ warcode mcp list
```

Add a remote server.

```bash
$ warcode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ warcode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ warcode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ warcode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ warcode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ warcode mcp logout sentry
```

View all subcommands and flags.

```bash
$ warcode mcp --help
```

## plugin

Manages plugins.

```bash
$ warcode plugin list
```

Include built-in server plugins.

```bash
$ warcode plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ warcode plugin add @example/warcode-tui
```

Check package plugins for updates.

```bash
$ warcode plugin check
```

Update package plugins.

```bash
$ warcode plugin update
```

Remove a plugin from global configuration.

```bash
$ warcode plugin remove @example/warcode-tui
```

View all subcommands and flags.

```bash
$ warcode plugin --help
```



Show model usage.


```bash
$ warcode stats --cost
```

Print JSON instead of a report.

```bash
$ warcode stats --json
```



## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ warcode serve
```

Bind to all interfaces on a fixed port.

```bash
$ warcode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ warcode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ warcode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ warcode pair
```

Use an external URL in the links.

```bash
$ warcode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ warcode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ warcode pair --remote --yes
```

View all subcommands and flags.

```bash
$ warcode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ warcode service start
```

Restart it.

```bash
$ warcode service restart
```

Show its status.

```bash
$ warcode service status
```

Stop it.

```bash
$ warcode service stop
```

Read a setting.

```bash
$ warcode service get hostname
```

Set a setting.

```bash
$ warcode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ warcode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ warcode service set env WARCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ warcode service unset hostname
```

View all subcommands and flags.

```bash
$ warcode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ warcode reload
```

## api

Makes a request to the running server.

```bash
$ warcode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ warcode api session.list --param limit=10
```

Send a JSON body.

```bash
$ warcode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ warcode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ warcode api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ warcode debug agents
```

List configuration sources.

```bash
$ warcode debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ warcode debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ warcode debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ warcode debug paths
```

Print a single path.

```bash
$ warcode debug paths db
```

View all subcommands and flags.

```bash
$ warcode debug --help
```

## upgrade

Upgrades Warcode to the latest or a specific version. Alias: `update`.

```bash
$ warcode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ warcode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ warcode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Warcode. Session data, configuration, and
state are not removed.

```bash
$ warcode uninstall
```

Preview what would be removed.

```bash
$ warcode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ warcode uninstall --help
```
